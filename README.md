# 谱声练习 · ScoreVoicePlay

把相册里的**五线谱演奏视频**变成可循环的分段练习工具：自定义 A/B 区间、每段两条备注（弹奏技巧 + 歌词）、
原声 / 自己的钢琴 / 自己的人声三条音轨、并且能自动对比打分。

纯前端 PWA（无构建、无依赖、无后端）。视频和录音只存在本机浏览器里，不会上传。

---

## 1. 快速开始

### 在 Mac 上先看看

```bash
cd ScoreVoicePlay
node server.mjs            # http://localhost:5173
```

### 在 iPad 上用（推荐流程）

iPad 的 Safari **只在 HTTPS 页面**里允许麦克风、Service Worker（离线）和「添加到主屏幕」。
所以有两条路：

**A. 部署到 GitHub Pages（推荐，一步一步）**

目标地址形如 `https://<你的用户名>.github.io/score-voice-play/`。仓库免费账号需要是 **public**，
但请放心：仓库里只有程序代码，**视频、录音、练习数据都不会上传**（它们只存在 iPad 本机浏览器里）。

1. **建仓库**：github.com → 右上角 `+` → New repository → 名字填 `score-voice-play` → Public →
   不要勾 README/gitignore/license → Create repository。
2. **传文件**（两种方式选一种）：

   **方式一：网页上传（不用装 git，最省事）**
   - 仓库页 → `Add file` → `Upload files`
   - 打开本机上的 `ScoreVoicePlay` 文件夹，把里面的**全部内容**拖进浏览器窗口
     （至少要有：`index.html`、`styles.css`、`manifest.webmanifest`、`sw.js`、`src/`、`icons/`、`.nojekyll`）
   - ⚠️ 不要拖 `.certs/`（那是本地自签证书的私钥）
   - 底下填一句说明 → `Commit changes`

   **方式二：命令行**
   ```bash
   cd /Users/xtesla/ScoreVoicePlay
   git init -b main
   git add .
   git commit -m "ScoreVoicePlay: iPad 五线谱分段循环练习"
   git remote add origin https://github.com/<你的用户名>/score-voice-play.git
   git push -u origin main
   ```
   （`.gitignore` 已经排除了 `.certs/`、`node_modules/`、`.DS_Store`）
3. **打开 Pages**：仓库 `Settings` → 左侧 `Pages` → `Build and deployment` →
   Source 选 **Deploy from a branch**，Branch 选 **main**、目录选 **/(root)** → `Save`。
4. **等 1 分钟左右**，页面顶部会出现 `Your site is live at https://<用户名>.github.io/score-voice-play/`。
   在 iPad Safari 打开这个地址即可（HTTPS，麦克风与"添加到主屏幕"都可用）。

> 应用里所有路径都是相对路径，所以放在 `/<仓库名>/` 这种子目录下也能正常联网、离线缓存、安装到主屏。

**以后想改代码怎么更新**：把改过的文件重新上传（网页上 `Add file → Upload files` 覆盖，或 `git push`），
Pages 会自动重新发布；iPad 上重新打开应用（或下拉刷新一次）就会拿到新版本，
应用检测到新版本时会提示"有新版本：下次打开或刷新后生效"。

**其他静态托管也可以**：Cloudflare Pages（`Create → Pages → Upload assets` 拖文件夹）、
Vercel、Netlify，或者公司内网的任意静态服务器——只要是 HTTPS 就行。

**B. 局域网自签 HTTPS（只想在自己家和 iPad 之间用）**

```bash
node server.mjs --https     # https://<你的Mac局域网IP>:5174
```

iPad 首次访问会提示证书不受信任：Safari 里点「显示详细信息 → 访问此网站」，
再到 `设置 → 通用 → 关于本机 → 证书信任设置` 打开 `ScoreVoicePlay Dev` 的完全信任。
（Mac 和 iPad 要在同一个 Wi-Fi；Mac 的防火墙要允许 node 接入。）

> 直接用 `http://192.168.x.x` 打开：播放、A/B、备注都能用，但**录音会被 Safari 拒绝**，也不会有离线和主屏图标。

## 2. 怎么用

### 载入

1. 点右上角 **选择五线谱视频** → 从「照片图库」选一段演奏录像。
   - 视频会被存进浏览器（IndexedDB），下次打开自动恢复。视频很大时可以正常用，但刷新后要重选。
2. （可选）点 **参考音频** 导入同一首曲子的音频文件（m4a / mp3）。
   - 自动解析不出音轨时（少数录屏文件），波形和评分就靠它；导入了就以它为准。

### 项目管理（保存 / 切换 / 搬运到别的设备）

顶栏的 **项目** 按钮打开项目库。每次编辑都会**自动保存**到本机，不用手动存；这里管的是"多个练习"和"搬家"：

| 操作 | 说明 |
| --- | --- |
| **新建项目** | 建一个空项目（沿用当前的音量/循环偏好），接着就选视频 |
| **保存副本** | 复制当前项目的分段与备注（共享同一份视频文件，不额外占空间） |
| **打开** | 切到列表里的任意项目；分段、备注、录音、A/B 全部跟着切换 |
| **改名 / 删除** | 删除只删这个项目自己的视频与录音，别的项目不受影响 |
| **导出当前项目** | 生成一个 `.svp.zip` 单文件：`project.json` + 视频 + 参考音频 + 全部录音 |
| **导入项目文件** | 选 `.svp.zip`（或旧的纯文本 `.json`）还原成一个新项目 |

导出时会问一次：

- **连视频与录音一起导出** —— 完整搬家/备份。文件大（视频多大就多大），但换设备后连录音和分数都在。
- **只导出分段与备注** —— 只有几 KB，适合发微信/邮件给别人照着练，或给自己留个"谱面笔记备份"。

`.svp.zip` 存在「文件」App 里就行，放到 iCloud Drive 就等于云端备份；用 AirDrop 传到另一台 iPad，
在那台设备打开本应用 → **项目 → 导入项目文件** → 选这个 zip，视频、分段、两条备注、录音会一起还原。

### 划段（A/B）

- 播放到句子开头 → 点 **设置A**；播放到句子结尾 → 点 **设置B**；再点 **添加行**。
- 也可以直接在底部**波形上拖动 A / B 两个小旗标**，松手就会自动试听这一段。
- 段落菜单（每行的 `⋯`）里可以把时间精确到 0.01s 微调、单独设置这一段的重复次数/间隔、复制、删除。

每行有**两条备注**：

| 字段 | 用途 |
| --- | --- |
| **技巧** | 弹奏要点：右手指法、踏板、力度、容易错的地方…… |
| **歌词** | 这一句的歌词 / 段落标记（A段、副歌…），配合「分句」可以整段歌词自动填 |

**点行首序号或时间文字** → 立刻从该句开头循环播放（次数、间隔按当前设置），这一行会被金色框住，
成为"当前工作段落"（录音、删除、评分都针对它）。播放时画面右下角会浮出这一行的技巧与歌词；
播放头经过别的段落时，那一行会亮起蓝色边框——只是跟播高亮，不会抢走当前工作段落。

### 重复与间隔

底部一排小胶囊：

- **重复**：不限 / 1 / 2 / 3 / 5 / 10 / 自定义次数
- **间隔**：自动 / 0.0 / 0.5 / 1.0 / 2.0 / 3.0 秒（两遍之间的停顿）
- 左上角会显示「第 n/N 遍」
- **单句重复**（工具栏按钮）：开 = 点句子只循环这一句；关 = 从这句开始一路连播到曲子结尾
- `1.0×` 可以切 0.5× / 0.75× / 1.25× / 1.5× 慢练

### 三条音轨

| 音轨 | 来源 | 说明 |
| --- | --- | --- |
| 原声 | 视频自带音轨 | 拖动滑杆 / 点名字静音 |
| 钢琴 | 你自己录的弹奏 | 与视频同步叠加播放，可单独调音量 |
| 人声 | 你自己唱 | 同上；评分时优先拿「你的钢琴」当基准 |

录音流程：点某行的 **🎹 录钢琴** 或 **🎤 录人声** →（可选预备拍倒数）→ 视频自动回到 A 开始播放、
同时开始录音 → 到 B 自动停止 → 自动和参考比对并给出分数。录音时主按钮会变成红色停止键。

- 只想听原声：点该行 **♪ 原声**（停止播放后自动恢复叠加）
- 看分数明细：点 **VS 对比**
- 换/删录音：设置 → 清空录音，或 VS 对比里的 **录音管理**（可以选「使用」某一条作为当前音轨）

> 录音想准，最关键是**戴耳机**：外放时原声会漏进麦克风，评分会被"污染"（听起来很准但分数低或反过来）。

#### 录音回放很小声怎么办（默认已处理）

麦克风录进来的声音通常比视频原声低 10–20 dB，而网页里 `<audio>` 的音量上限就是 100%，拉满也没用。
所以每条录音在保存时会量一次电平（峰值 / RMS），回放时用 WebAudio 增益节点把它**自动放大到和原声（人声则和自己的钢琴录音）一样响**，
后面还串了一个温和的压缩器防止爆音；混音滑杆仍然控制相对音量。规则：

- 录得够响 → 基本不放大（×1.0 左右），不会无谓地把底噪抬起来
- 录得小声 → 自动放大，最多 ×16（+24 dB）
- 判断依据写在「VS 对比」和「录音管理」里：`回放自动放大 ×N`、`原始 -37dBFS`
- 旧版本录的音第一次播放时会自动补算（可能要等一下下）
- 想去掉这个行为：设置 → **录音回放自动放大 → 关**（重新打开 App 后彻底不经过 WebAudio）
- 导出的 `.svp.zip` 里是**原始电平**，换设备导入后照样会自动放大

## 3. 评分是怎么算的

不是"听起来像不像"的玄学，而是把两段音频都做音高/节奏特征后对齐比较：

1. **特征提取**（`src/analyze.js`）
   - 基频 F0（NSDF / McLeod 方法）→ MIDI 音高
   - 12 维色度 chroma（和声内容，天然忽略八度）
   - 谱通量 onset 包络（起音）
2. **对齐**：带宽约束 DTW（允许几拍的快慢差异、起步早晚）
3. **打分**
   - **钢琴（复音）**：音准看 chroma 相似度（你弹的和原曲的和声重合度）；节奏看起音是否落在原曲的拍点上
   - **人声**：音准看每个唱出的音高类别是否落在「此刻参考的和声」里（所以低八度唱不会被扣分）；节奏看咬字起音与参考起音的对齐
   - 综合 = 音准 × 0.64 + 节奏 × 0.36（"差的成分" = 100 − 综合）
   - 人声的参考默认是**你自己的钢琴录音**（若这一段录过），否则是原声 → 这就是"歌词与自己弹奏的匹配度"

分数是**相对参考**的练习指标，不是绝对音准评级。麦克风距离、房间混响、外放串音都会影响。

## 4. 文件结构

```
index.html              页面骨架
styles.css              深色主题 / iPad 横竖屏适配 / 安全区
manifest.webmanifest    PWA 清单
sw.js                   离线缓存（外壳）
icons/                  图标（脚本生成）
src/app.js              业务编排：媒体、A/B、段落、录音、评分、导入导出
src/ui.js               DOM 渲染与交互
src/player.js           播放引擎（三音轨、A-B 循环、重复/间隔、漂移校正）
src/recorder.js         麦克风录音 + 实时电平/音高 + 预备拍
src/waveform.js         可拖拽 A/B 的波形画布
src/analyze.js          DSP 与评分（纯函数，可在 Node 里测）
src/audio.js            解码、重采样、波形峰值、时间格式化
src/db.js               IndexedDB 封装（项目库 + 媒体二进制）
src/zip.js              极简 zip 读写（单文件项目导出/导入）
src/state.js            项目数据模型与持久化
server.mjs              本地静态服务器（含 --https 自签证书）
scripts/make-icons.mjs  生成图标
tests/analyze.test.mjs  评分引擎单元测试
```

调试：浏览器控制台里有 `window.SVP`，可以直接摸到 `project / player / wave / recorder`。

```js
SVP.project.segments               // 所有段落
SVP.player.setLoop({a: 2, b: 8})   // 手动改循环
```

## 6. 已知限制

- **iOS 音量**：iPad Safari 上 `<video>.volume` 可能被忽略（只有静音生效）。如果「原声」滑杆没用，
  打开 **设置 → 原声走 WebAudio 混音**，用增益节点控制（改完刷新一次）。
- **自签证书**必须手动信任，否则 iPad 上麦克风仍会被拒。
- **存储跟着网址走**：数据存在"这个网址 + 这个浏览器"下。如果你把仓库改名、从 `github.io` 换到自定义域名、
  或从 HTTP 换成 HTTPS，等于换了网址，iPad 上的旧项目不会自动出现——**换地址前先在旧地址里「项目 → 导出当前项目」，
  到新地址再「导入项目文件」**。
- **存储**：视频/录音都在浏览器里（IndexedDB；某些 WebKit 版本不能存 Blob，会自动退化成存字节数组）。
  Safari 清理网站数据会一起消失；换设备请用「导入 / 导出」搬运段落文本（不含媒体文件）。
- **导出体积**：连视频一起导出时，整个 zip 要先在内存里拼出来；视频超过 300MB 建议选「只导出分段与备注」，
  或者先把视频单独压缩，导入后再重新选视频。
- **评分的边界**：极快的炫技段、双音/和弦很多时，chroma 相似度会偏保守；说唱/念白类"歌词"没有音高，人声音准分参考意义有限。
- 语音识别歌词只在支持 `SpeechRecognition` 的浏览器可用（Safari 一般没有），更稳的是系统「听写」后粘贴。
